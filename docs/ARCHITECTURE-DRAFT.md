# ARK 工作站 —— 架构初稿 v0.1

> 这是 P1 阶段的**讨论稿**，不是 PLAN，也不是 SDS。目的是把"功能一大堆"收敛成"一个内核 + 一堆插件"。
> 所有 `[?]` 是需要你拍板的地方，本轮末尾用 ask_user_question 一次问掉。

---

## 一、先说结论：这个项目的成败只有一件事

**功能数量不是问题，插件边界才是。**

二十个功能写在一个 React 应用里，三个月后必死：样式互相污染、状态互相纠缠、加一个功能要动十个文件。所以整个项目的技术核心只有一个：

> **一个极简的 Shell（外壳）+ 一个插件协议。所有功能，包括"设置"和"桌面"，都是插件。**

Shell 只负责五件事：**窗口与呼出、路由与布局、主题与动效、权限与沙箱、数据与 AI 门面**。
插件负责其余一切。这样加第 30 个功能不需要动第 1 个功能。

## 二、六条设计原则（写进 PLAN，作为评审依据）

| # | 原则 | 反面（一旦违反会怎样） |
|---|---|---|
| P1 | **Shell 薄，插件厚** | Shell 里出现业务逻辑 → 半年后 Shell 变成 8000 行的上帝文件 |
| P2 | **不重写轮子，只做桥接** | 自己写画布/剪辑引擎 → 三年也追不上 Excalidraw 和 ffmpeg |
| P3 | **一切皆命令**（命令面板是唯一主入口） | 功能越多按钮越多 → 桌面变成工具栏垃圾场 |
| P4 | **设计 token 单一来源** | 每个插件自带样式 → 审美三天就崩 |
| P5 | **数据全本地、明文可导出** | 存云端或私有格式 → 哪天工具挂了你的十年笔记一起没了 |
| P6 | **默认隐形，显式呼出** | 常驻托盘/开机弹窗 → 从"私人空间"变成"又一个烦人软件" |

## 三、功能域全景（含你没提、但你会想要的）

### A. 创作域（你已提的 7 项）

| 功能 | 实现路径（不自己写引擎） | 难度 |
|---|---|---|
| 编程 | Monaco 编辑器 + LSP 客户端 + 内置终端（xterm.js + node-pty）+ 文件树 | 中 |
| 绘画 | 嵌入 Excalidraw / tldraw（矢量、手绘风）；像素画用自写 canvas 网格工具 | 低-中 |
| 建模 | 轻量预览用 Three.js + GLTF；重型接本机 Blender（`blender --background` + Python 脚本桥） | 中-高 |
| 动画 | 时间轴 + 关键帧编辑（自己写，但只做 2D 变换/透明度层）+ 导出序列帧给 ffmpeg | 高 |
| 剪辑 | ffmpeg 做实际编码，自己只做"时间轴 UI + 剪辑决策表（EDL）" | 高 |
| 音乐 | Tone.js（合成器/音序器）+ Web Audio 分析；母带/转换走 ffmpeg | 中 |
| 游戏 | Phaser 3 做运行时，做"关卡编辑器 + 试玩面板"，不做引擎 | 高 |

> **必须接受的现实**：剪辑和动画是这里最重的两个。建议第一期只做"导入→裁切→拼接→导出"的粗剪，不要一上来做多轨特效。

### B. 效率域（补的）

- **全局命令面板**（Ctrl+K / 呼出后直接打字）：一切操作的唯一入口，支持自然语言（"把桌面截图存到项目文件夹"）
- **文件速搜**：本地索引（启动时建一次 SQLite FTS5，增量更新），比 Windows 搜索快一个量级
- **剪贴板历史**：带类型识别（文本/图片/文件/颜色/代码），可固定、可搜索
- **窗口管理**：快捷键贴边/分屏/置顶/跨虚拟桌面移动
- **截图与 OCR**：区域截图 → 本地 OCR（PaddleOCR 或 Windows OCR API）→ 直接可复制文字
- **批量重命名 / 批量转换**：正则重命名 + 图片/视频批量转码
- **定时与自动化**：cron 式任务 + "当 X 发生则做 Y"（文件落到某目录 → 自动处理）
- **番茄钟 / 时间账本**：记录每个插件被用了多久（顺便产出"我到底在忙什么"数据）

### C. 知识域（补的，这块长期价值最高）

- **笔记**：Markdown + 双向链接（`[[ ]]`）+ 图谱视图
- **本地全文检索**：笔记 / PDF / 代码 / 图片 OCR 文本，统一搜
- **稍后读**：网页剪藏 → 清洗正文 → 进检索库
- **闪卡复习**：从笔记里划重点自动生成卡片（SM-2 算法）
- **文献/资料管理**：标签 + 引用导出 BibTeX

### D. 生活域（补的）

- 习惯打卡（连续天数、热力图）
- 账本（记账 + 月度分类图表）
- 订阅管理（到期提醒、年化成本）
- 密码保险箱（本地 AES-256-GCM 加密，主密码解锁）
- 私密空间（加密便签，演示模式一键隐藏）
- 家庭库存 / 收藏品清单

### E. 系统域（补的，用起来最爽）

- 性能监控（CPU/内存/磁盘/网络/GPU 曲线）
- 磁盘占用可视化（treemap，找出谁吃了 200G）
- 启动项 / 服务 / 计划任务 管理
- 端口占用与进程树（`netstat` 图形化，一键 kill）
- 环境变量 / Hosts / PATH 编辑器（改前自动备份）
- 快捷命令库（长命令存成按钮，带参数表单）

### F. 网络与开发工具域（补的）

- 下载器（aria2 前端，多线程 + 断点续传）
- API 调试台（类 Postman 精简版，集合存本地）
- 正则测试器 / 编码转换 / JSON↔YAML↔CSV / 时间戳↔日期 / Base64 / 哈希 / JWT 解析
- 本地服务面板（起停 docker compose / 本地静态服务器 / 端口转发）

### G. AI 域（贯穿，不是独立模块）

统一门面 `ai.*`，所有插件共用，好处是换模型只改一处：

- `ai.chat()` 对话 / `ai.instruct()` 单轮指令 / `ai.embed()` 向量 / `ai.vision()` 看图 / `ai.transcribe()` 语音
- **本地 + 云双通道**：Ollama（离线、免费、隐私）优先，云端（DeepSeek/OpenAI 兼容）处理难任务，按规则路由
- 落到具体功能：
  - 命令面板自然语言 → 意图解析成命令
  - 编程：解释报错、生成 diff、写测试
  - 绘画：文生图、局部重绘、抠图（走本地 SD 或云端 API）
  - 剪辑：自动生成字幕、按语音切分、粗剪建议
  - 音乐：和弦进行建议、歌词生成
  - 知识：RAG over 本地笔记/PDF，问答带引用
  - 系统：读日志找异常、解释这段命令做什么

### H. 独属于你的部分（这就是"个人工作站"和"工具箱"的区别）

1. **Workspace 模式**：一键切"编程/绘画/剪辑/写作/夜间"，切换时**布局 + 打开的插件 + 主题色 + 壁纸 + 音量**一起变
2. **今日仪表盘**：今天要做什么 / 最近在改哪个文件 / 连续创作天数 / 一句 AI 生成的今日提示
3. **AI 长期记忆**：跨插件共享的"你是谁、你在做什么项目、你的偏好"，所有 AI 功能自动带上
4. **时间机器**：所有编辑动作自动快照（SQLite + 内容寻址），任何东西可回滚到任意时刻
5. **专注模式**：全屏隐匿一切 + 白噪音 + 屏蔽指定网站
6. **演示模式**：一键隐藏私密插件、脱敏路径、暂停通知
7. **彩蛋**：隐藏手势触发的小玩意（你说要"特殊方式打开"，这本身就该有仪式感）

## 四、架构分层

```
┌─────────────────────────────────────────────────────┐
│  Renderer: Shell                                     │
│  ┌──────────┬──────────┬──────────┬───────────────┐  │
│  │ 桌面/桌面  │ Dock     │ 命令面板  │ 通知/Toast    │  │
│  │ 图标网格   │          │ (Ctrl+K) │               │  │
│  └──────────┴──────────┴──────────┴───────────────┘  │
│  插件宿主：每个插件跑在隔离的 WebContentsView 里        │
└──────────────────────┬──────────────────────────────┘
                       │ IPC (带命名空间 + 权限校验)
┌──────────────────────┴──────────────────────────────┐
│  Main: Kernel                                        │
│  窗口管理 · 全局手势/热键 · 插件生命周期 · 权限网关     │
│  数据层(SQLite + 迁移) · 文件代理 · 任务队列 · AI 路由  │
└──────────────────────┬──────────────────────────────┘
                       │ utilityProcess（Node 侧插件）
┌──────────────────────┴──────────────────────────────┐
│  外部能力：ffmpeg · Blender · Ollama · Everything索引 │
└─────────────────────────────────────────────────────┘
```

**为什么插件要隔离到独立 WebContentsView**：样式不互相污染（P4 的物理保障）、崩溃不拖垮 Shell、权限可精确到插件。

## 五、插件协议草案

```jsonc
// plugins/<id>/manifest.json
{
  "id": "com.ark.notes",
  "name": "笔记",
  "version": "1.0.0",
  "icon": "icon.svg",
  "entry": "index.html",          // renderer 侧
  "main": "main.js",              // 可选，跑在 utilityProcess
  "permissions": ["fs:read:workspace", "db:own", "ai:instruct"],
  "commands": [                    // 自动进命令面板
    { "id": "notes.new", "title": "新建笔记", "keys": "Ctrl+Alt+N" }
  ],
  "contributes": {
    "desktopIcon": true,
    "settings": "settings.json"    // 声明式设置界面，Shell 自动渲染
  }
}
```

- **权限未声明即拒绝**：插件调 `fs.read` 但 manifest 没写 `fs:read:workspace` → 直接抛错并记日志
- **数据隔离**：每个插件一个 SQLite schema，跨插件读写必须走显式 API
- **设置界面声明式**：插件只给 JSON，Shell 用统一控件渲染 → 设置页审美也统一
- **打包**：插件就是一个目录，丢进 `plugins/` 即安装（第一期不做在线市场）

## 六、"隐形 + 特殊方式打开"方案对比

| 方案 | 隐蔽性 | 误触 | 实现成本 | 备注 |
|---|---|---|---|---|
| 全局热键（如 Ctrl+Alt+`） | 中 | 低 | 极低 | 会被别的软件占用；记不住 |
| 屏幕边缘热区（鼠标停角落 1s） | 高 | 中 | 低 | 全屏游戏/拖窗口时容易误触 |
| **连击序列**（3 秒内连按 Esc 三次） | 高 | 极低 | 低 | 有点像黑客电影，有仪式感 |
| **鼠标手势**（按住右键画 L 形/圆圈） | 最高 | 极低 | 中 | 独属于你的密码，适合做主入口 |
| 键入暗语（在任意处打 `ark` + 回车） | 中 | 低 | 低 | 需要全局键盘钩子 |

**建议：手势为主 + 热键为备 + 边缘热区兜底**，三者可各自开关。手势识别用 $1 Unistroke Recognizer（约 100 行，支持你自己录模板）。

配套的三个"隐形"细节：

1. `win.setSkipTaskbar(true)` —— 不进任务栏、不进 Alt-Tab
2. `win.setContentProtection(true)` —— 录屏/截图/投屏时窗口内容为黑（关键，符合"独属于我个人"）
3. 呼出用淡入 + 缩放动效，收起用反向 + 失焦自动隐藏（可配置延迟）

## 七、审美系统（"好看"必须被工程化，否则会烂）

**设计 token 是唯一来源**，插件只能用 token，不许写死颜色：

```ts
// tokens: 全部由主题生成
{ color: { bg, surface, surfaceHi, border, text, textDim, accent, accentSoft, danger },
  radius: { sm: 6, md: 10, lg: 16, xl: 24 },
  space: [4, 8, 12, 16, 24, 32, 48],
  type: { display, h1, h2, body, caption, mono },  // 固定 6 级
  shadow: { card, float, modal },
  motion: { fast: 120, base: 200, slow: 320, spring: '...' } }
```

- **三套内置主题**：深空（默认，近黑 + 一点冷蓝）、羊皮纸（浅色、米白、纸纹）、高对比（无障碍）
- **壁纸取色**：塞一张壁纸，自动生成整套主题（accent 取自最饱和色，背景取自暗部）
- **玻璃拟态**：`backdrop-filter: blur(24px)` + 1px 内高光边 + 18% 透明层，这是"高级感"的主要来源
- **动效纪律**：全站只用一套 spring 预设 + 三个时长档。**插件禁止自定义动画曲线**（这条比配色重要）
- **排版纪律**：行高 1.6、正文 14px、标题字重 600、禁用超过 6 级字号

## 九、非目标（第一期明确不做）

- N1 不自己实现视频编解码、图像处理算法（全部 ffmpeg / sharp）
- N2 不做多用户、不做账号系统、不做云同步（数据只在本机，导出即备份）
- N3 不做在线插件市场（只支持本地目录安装）
- N4 不做移动端 / 网页版
- N5 不做 3D 建模引擎（只做预览 + 调 Blender）
- N6 不做多轨视频特效（第一期只做粗剪）
- N7 插件不做热更新（改了重启）

## 十、风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 功能贪多，每个都半成品 | 项目烂尾（最大风险） | 严格分期：第一期只交付 Shell + 3 个核心插件 |
| Electron 体积大（~200MB） | 占空间 | 接受；个人工具不追极致 |
| 手势识别在全局钩子下误触发 | 烦人 | 手势默认关闭，先用手势+热键二选一验证 |
| ffmpeg/Blender 依赖外部安装 | 装不上就跑不了 | 启动时检测 + 引导安装 + 降级提示 |
| 插件权限设计过严 | 自己写插件嫌麻烦 | 权限表先小后大，个人项目可留 `dev:unsafe` 开关 |
| `setContentProtection` 与某些显卡驱动冲突 | 窗口黑屏 | 做成可开关，默认关 |

## 十一、建议的分期（把"一天跑完"变成"一周跑完第一期"）

| 期 | 内容 | 出口 |
|---|---|---|
| **S0 内核** | Shell + 主题系统 + 命令面板 + 插件宿主 + 手势呼出 | 能呼出、能装一个 hello 插件、能切主题 |
| **S1 三件套** | 笔记 / 文件速搜 / 剪贴板历史 | 日常真的会用 |
| **S2 编程** | Monaco + 终端 + 文件树 | 能替代 VSCode 做轻量改代码 |
| **S3 AI 门面** | Ollama + 云双通道 + RAG over 笔记 | 命令面板能听懂人话 |
| **S4 创作** | 绘画(Excalidraw) → 剪辑(ffmpeg 粗剪) → 音乐(Tone.js) | 各有一个能用的最小闭环 |
| **S5 系统与生活** | 监控 / 磁盘 / 端口 / 账本 / 习惯 | 补齐"工作站"感 |
| **S6 独家** | Workspace 模式 / 时间机器 / 演示模式 / 彩蛋 | 变成"你的" |

> 每一期结束都是一个**可日常使用**的版本，不是半成品。这是不烂尾的唯一办法。
