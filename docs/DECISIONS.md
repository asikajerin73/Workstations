## 记录

### ADR-000 采用"文档先行 + 对抗评审 + 上下文隔离实施"流水线

- 日期：`[DATE]`
- 状态：ACCEPTED
- 背景：单会话长时间开发会因上下文膨胀导致约束遗忘与自我确认偏误。
- 决定：计划 → grill → 独立评审 → SDS → 独立评审 → 多 agent 实施（写/审分离）。
- 后果：前期文档成本增加约 30%，但实施期返工率显著下降；主会话必须克制"自己写代码"的冲动。
- 触发重新评估：任务粒度普遍小于 30 分钟时，流程开销大于收益，可合并评审环节。
