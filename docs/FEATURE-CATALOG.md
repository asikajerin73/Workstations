## 依赖关系图（决定实施顺序）

```
Shell 内核 ──┬─► 主题引擎 ──► 所有 UI
             ├─► 命令面板 ──┬─► 所有插件的命令注册
             │              └─► AI 自然语言入口(S3)
             ├─► 插件宿主 ──► 所有插件
             ├─► 数据层 ────┬─► 笔记(S0)
             │              ├─► 剪贴板历史(S1)
             │              ├─► 时间机器(S2)
             │              └─► 闪卡/账本/习惯(S2)
             └─► 触发层 ────► 手势/热键/热区

文件索引(S1) ──┬─► 文件速搜
                └─► 素材库(S3)
AI 门面(S0 骨架/S3 实装) ──► 所有 AI 落点
```

**关键洞察**：`数据层 + 插件宿主 + 命令面板` 是三条主干，必须最先做且做对。其余全是挂在上面的插件，可以任意顺序、任意期，甚至可以不做——这就是插件架构的价值。
