## 设计边界与缺口

- `createThemeEngine(registry)` 是可注入的纯引擎边界，状态封闭于实例。生产实例只注册 `deepSpace`。验证 theme ID 在遍历/写入变量前执行。
- `parchment` 与 `high-contrast` 仅有 ID 定义，缺少完整 palette token 值。**CONTRACT_GAP**：本任务未编造其数据，生产 registry 未注册它们；请求这些 id 返回 `E-THEME-001`。
- **CONTRACT_GAP**：SDS 的 CL-231 涵盖 main 持久化及 Shell/插件广播，但数据库、IPC、插件接口依赖后续任务；本任务只交付 renderer/apply 子集，未实现持久化和广播。
- **ASSUMPTION**：初始化时通过 `src/renderer/main.tsx` 的单一 adapter 入口应用 deep-space；没有设置持久化状态，因此构建期 tokens.css 与运行期应用保持一致。
- **ASSUMPTION**：factory registry 的重复 ID 采用 `Map` 后写覆盖语义；生产 registry 无重复 ID，测试注册表也使用唯一 ID。
