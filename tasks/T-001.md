## 步骤

### 1. Node 20 LTS

```powershell
# 用 npmmirror 下载（官方源太慢）
$url = 'https://npmmirror.com/mirrors/node/v20.18.1/node-v20.18.1-win-x64.zip'
$dst = 'F:\gal\workstation\.tools\node-v20.18.1-win-x64'
# 下载 → 校验大小 > 25MB（< 25MB 视为坏文件，重下）→ 解压到 $dst
```
- 若 npmmirror 不可用，回退 `https://nodejs.org/dist/v20.18.1/node-v20.18.1-win-x64.zip`。
- 把 `$dst` 加入**用户 PATH**（不改系统 PATH）。

### 2. pnpm 9

```powershell

```
- 若 corepack 不可用，用 `npm i -g pnpm@9.15.9 --prefix F:\gal\workstation\.tools\npm-global` 并把该目录加入用户 PATH。

### 3. `.npmrc`

```ini

electron_builder_binaries_mirror=https://npmmirror.com/mirrors/electron-builder-binaries/

```

### 4. 最小工程验证 better-sqlite3

```powershell
mkdir F:\gal\workstation\probe-t001
cd F:\gal\workstation\probe-t001
pnpm init
pnpm add -D electron@33
pnpm add better-sqlite3@11.10.0
pnpm add -D @electron/rebuild
npx @electron/rebuild -f -w better-sqlite3
```

写 `main.js`：
```js
const { app } = require('electron');
const Database = require('better-sqlite3');
app.whenReady().then(() => {
  const db = new Database('probe.db');
  db.pragma('journal_mode = WAL');
  const mode = db.pragma('journal_mode', { simple: true });
  db.exec('CREATE VIRTUAL TABLE IF NOT EXISTS t USING fts5(a)');
  console.log('PRAGMA journal_mode =', mode);
  console.log('fts5 = OK');
  db.close();
  app.quit();
});
```

运行 `npx electron main.js`，期望输出含 `journal_mode = wal` 与 `fts5 = OK`。
