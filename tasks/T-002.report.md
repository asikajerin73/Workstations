## CONTRACT_GAP

### CONTRACT_GAP-1：`@types/node` 不在依赖白名单，但 `types: ["node"]` 需要它
`@types/node` 仅作为 `electron` 的传递依赖存在于 `node_modules/.pnpm/@types+node@20.19.43/`，
pnpm 严格模式**不提升到顶层** `node_modules/@types/node`，故 `"types": ["node"]` 报：
```
error TS2688: Cannot find type definition file for 'node'.
```
**处置**：按任务卡第 2 步预案改为 `"types": []`，未加任何依赖。`@types/node` 随后由模块解析路径自动拾取，`pnpm typecheck` EXIT=0。
**建议**：若希望显式声明，需把 `@types/node` 加入 17 个 devDeps 白名单（当前 A2 会拒绝）。

### CONTRACT_GAP-2：CL-260b 的 003 按字面实现不可达
CL-260b 规定「zod 通过但 id 不匹配 `^[a-z0-9]+(\.[a-z0-9-]+)+$` → E-PLUGIN-003」，
但 §4.3 的 `PluginManifestSchema` 里 `id` 字段**带同一个正则**，非法 id 必然先在 schema 层失败落到 002，003 永远不可达（AC-M07-16 的 `id: "Bad_ID"` 会返回 002）。
**处置**：把「id 是字符串但语义非法」提前到 schema 之前判定（`validateManifest` 顶部），其余 schema 错误仍归 002；id 重复判定保留在 schema 之后。五条错误码各有一条单测覆盖。
**建议**：SDS 明确「id 语义」与「schema 校验」的优先关系，或从 schema 中移除 id 正则。

### CONTRACT_GAP-3（A7 实测发现的运行期缺陷，已修）：`webPreferences.preload` 必须绝对路径
任务卡第 5 步给的 `PRELOAD_SHELL_PATH = 'out/preload/index.js'` 是相对路径。Electron 直接拒绝：
```
[ERROR:web_contents_preferences.cc(238)] preload script must have absolute path.
```
且 **preload 静默不加载**，renderer 里 `window.ark` 恒为 `undefined`。
typecheck / lint / test / build 四条命令**全都抓不到**（不真正启动 Electron）。
**处置**：`buildWindowOptions(preloadAbsPath)` 改必填参数，由 `src/main/index.ts` 用 `join(HERE, '../preload/index.js')` 注入绝对路径（`HERE` 由 `fileURLToPath(import.meta.url)` 推导，因 `"type": "module"` 下无 `__dirname`）。修后探针确认 `ark:"object"`、`arkVersion:"33.4.11"`。
**建议**：SDS 的 `buildWindowOptions` 签名补注「preload 路径由调用方注入绝对路径」；后续涉及 preload 的任务卡都应强制「实跑一次 + 断言 `window.ark` 存在」。

### CONTRACT_GAP-4（工程量，非阻塞）：`@typescript-eslint/*` 版本上界
`^8.18.2` 会解析到 8.72.1，其传递依赖 `eslint-visitor-keys@5.0.1` 要求 Node `^20.19.0 || ^22.13.0 || >=24`，本机 **20.18.1**，配合 `.npmrc` 的 `engine-strict=true` 直接安装失败：
```
ERR_PNPM_UNSUPPORTED_ENGINE ... Expected version: ^20.19.0 || ^22.13.0 || >=24, Got: v20.18.1
```
**处置**：把这两个包锁定到任务卡白名单的字面版本 `8.18.2`（不带 `^`），未新增依赖、未改白名单集合。
**建议**：统一 Node 版本口径（`engines.node: ">=20 <21"` 与 npm 包要求的 20.19+ 冲突），或把这两个包在任务卡里写成精确版本。
