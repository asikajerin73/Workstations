## 接口要求

`window.ts` 必须提供可注入边界，使单测无需启动 Electron（与 T-003 的 `createThemeEngine` 同思路）：

```ts
export interface BrowserWindowLike {
  setBounds(b: Rectangle): void;
  setAlwaysOnTop(flag: boolean, level?: string): void;
  show(): void;
  hide(): void;
  focus(): void;
  isVisible(): boolean;
  isFocused(): boolean;
  isAlwaysOnTop(): boolean;
  isDestroyed(): boolean;
  setSkipTaskbar(flag: boolean): void;
  webContents: {
    send(channel: string, ...args: unknown[]): void;
    isDestroyed(): boolean;
  };
  contentView: unknown;
  once(event: 'ready-to-show', cb: () => void): void;
  on(event: string, cb: (...args: unknown[]) => void): void;
  removeAllListeners(): void;
}

export interface WindowDeps {
  createWindow(opts: WindowOptions): BrowserWindowLike;
  getDisplayNearestPoint(pt: { x: number; y: number }): DisplayLike | undefined;
  getPrimaryDisplay(): DisplayLike;
  getCursorScreenPoint(): { x: number; y: number };
  now(): number;
  log(level: 'warn' | 'error', msg: string, extra?: Record<string, unknown>): void;
  listFlushTargets(): readonly FlushTarget[];
}

export interface FlushTarget {
  pluginId: string;
  flush(timeoutMs: number): Promise<void>;
}

export function createWindowApi(deps: WindowDeps, preloadAbsPath: string): WindowApi;
```

- `summon()` 严格按：`setBounds(computeWindowBounds(display))` → `setAlwaysOnTop(true,'screen-saver')` → **取 `t0 = deps.now()`** → `show()` → `focus()` → `webContents.send('window:summoned', { t0 })`。
- `hide()` 严格按：`isFlushing = true` → `await flushAllPlugins({timeoutMs:1000})` → `send('window:hiding')` → `await waitForRendererExit(150)` → `setAlwaysOnTop(false)` → `hide()` → `isFlushing = false`（**用 try/finally 保证复位**）。
- `waitForRendererExit(ms)`：发 `window:hiding` 后等 `window:hidden-ack`；超时 resolve(false)，收到 ack resolve(true)。**禁止**实现成纯 `setTimeout` sleep。
- `flushAllPlugins`：`Promise.allSettled` 并发，逐插件 `timeoutMs` 超时；返回 `{ok, timedOut}`。`listFlushTargets()` 默认返回空数组。
- `E-WIN-010`：`getDisplayNearestPoint` 返回 undefined → 回退 `getPrimaryDisplay()`。
- `E-WIN-011`：`show()` 抛错 → 销毁旧窗口、重建、**重试一次**；再次失败则抛出。
- `getContentView()` 返回 `win.contentView`，**不得用 `any`**。

`src/main/ipc.ts` 必须：

```ts
export function registerTestChannels(deps: {
  ipcMain: { handle(channel: string, fn: (...a: unknown[]) => unknown): void; removeHandler(channel: string): void };
  api: WindowApi;
  isPackaged: boolean;
  env: NodeJS.ProcessEnv;
}): void;
```

- 仅当 `!isPackaged && env.ARK_E2E === '1'` 时注册 `ipcMain.handle('test:summon', ...)`；否则**不注册任何 handler**（AC-M02-10：未注册时 invoke 必须 reject）。

`preload/shell.ts` 暴露（保持已有 `version` 字段不变）：

