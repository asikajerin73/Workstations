# T-003：主题引擎

> 目标：完成 M-04 主题引擎的基础实现与可验证切换；不扩大 palette 设计。
> 上位契约：`AGENTS.md` > `docs/SDS.md` v1.3 > `docs/PLAN.md` v3.2 > `tasks/LEDGER.md` > 本卡。

## 范围

- 接入当前权威 token（`deepSpace`），从 renderer 唯一写入点 `document.documentElement.style.setProperty` 应用变量。
- 实现主题 registry / apply 流程；有效主题切换后返回成功并更新 CSS custom properties。
- 对未知主题 ID 返回 `ArkError('E-THEME-001', ...)`，且不得改变当前 DOM 变量或当前主题状态。
- 覆盖 `surfaceBlur: 0` → `--ark-surface-blur: 0px`。
- 保持无副作用 shared 纯函数；renderer 的 DOM 写入限制在 theme adapter/engine 单一入口。

## 本任务不做

- `src/main/theme.ts`、SQLite 持久化、IPC、插件广播、preload 事件订阅。这些依赖 T-004/T-005/T-008 的窗口/数据/插件接口，后续任务接入。
- 新增 `parchment` / `high-contrast` 的 palette。PLAN/SDS 只定义了 ID，未定义其完整 `Theme` 字段值；不得凭空发明。实现结构应允许未来注册多主题；本任务记录 `CONTRACT_GAP`，由调度者决定何时补产品 token。
- 颜色 ESLint 规则及 fixtures（归 G-5/M6）；本任务仅消费现有 tokens 与已就位的 lint 入口。

## 接口要求

以现有 `src/shared/tokens.ts` 为基础，按 SDS 定义实现。可以新增纯数据 `themes` registry，但当前只有 `deepSpace` 一套有数据。DOM adapter 建议接口：

```ts
export interface ThemeTarget {
  setProperty(name: string, value: string): void;
}
export function applyTheme(target: ThemeTarget, themeId: string): Theme;
```

具体错误类型须使用现有 `ArkError` 与 `E-THEME-001`；不可用原生字符串错误。未知 ID 校验必须发生在任何变量写入之前。适配器允许传 `document.documentElement.style`，单测传 fake target。

`Theme` 当前字段和值格式按 `tokens.ts` 与 `tokens.data.json`。变量写入必须遍历 `themeToCssVars(theme)` 的返回值，不得另外维护第二份 CSS 属性表。运行时只有 theme engine/apply adapter 可以调用 `setProperty('--ark-…')`；组件只消费变量。
